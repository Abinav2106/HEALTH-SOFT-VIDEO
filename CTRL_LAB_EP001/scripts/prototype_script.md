# Prototype sequence — "The claim check" (internal quality gate, ~25 s)

Purpose: test the EffectCraft pipeline, PATCH rig, type system, one explanatory animation,
one illustrative demonstration, a transition, narration and SFX.
It makes **no claim about any real product**. The interface shown is a labelled illustrative reconstruction.
It doubles as a candidate for the episode's channel intro (00:35–01:00) once the subject is locked.

| # | Speaker | Line | Visual |
|---|---|---|---|
| P1 | NARRATOR | Every AI tip online comes with a promise. Ten times faster. Works every time. | Glossy promise card slides in: "10× FASTER". PATCH, on the desk, turns to look at it. |
| P2 | PATCH | That sounds impressive. Let's see whether it actually works. | PATCH leans in; eyes narrow to "inspect". Status light off. |
| P3 | NARRATOR | So every trick here goes through the same three checks. | The promise card flips and unfolds into a three-row checklist (object continuity). |
| P4 | NARRATOR | Where the feature lives. What you actually do. And what happened when we tried it. | Rows tick in one by one, timed to each phrase. |
| P5 | NARRATOR | If a step fails, you'll see that too. | Illustrative interface: cursor clicks Run; result card returns an error row; PATCH notices, eyes go to "error"; then "found it": the orange indicator pulses. |
