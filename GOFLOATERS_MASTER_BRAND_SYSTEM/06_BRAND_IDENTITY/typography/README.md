# Typography

* **Wordmark:** preserved as traced vector artwork (`02_MASTER_IDENTITY/vectors/gofloaters_wordmark*.svg`). The original typeface has **not** been identified. Never re-type the wordmark.
* **Proposed families** (all SIL Open Font License, files in `fonts/` with their licences):
  * Display: **Bricolage Grotesque** 600/700/800, for hero headings, section titles and campaign lines
  * Text and UI: **Inter** 400–700, for subheadings, body text and interfaces
  * Labels: **JetBrains Mono** 400/600, for interface labels and specs (caps, +8% tracking)
* The hierarchy (sizes and leading) is on `typography_hierarchy_sheet.png` and on page 24 of the guidelines.
