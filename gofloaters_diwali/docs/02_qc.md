## Known limits of this build

1. **Urban plates** (scene 04) and the dusk end card are built in code as stylised cinematic illustrations. They are not photographic. No real footage of Indian cities was available, and generating any was ruled out.
2. **Sound is temporary**: an original synthesized score and effects. Swap in licensed music when it exists.
3. The **game route overlay** and the **workspace card rectangle** are placeholders. Align them in `motion/config.js` to the real recording.
4. The `Amazon` name appears as text only, with no Amazon logo. Confirm usage with the voucher partner's brand terms. No T&C line was added, because none was supplied.
