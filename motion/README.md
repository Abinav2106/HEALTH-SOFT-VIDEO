# Motion — Remotion motion graphics

Programmatic motion graphics with [Remotion](https://www.remotion.dev/docs) 4.0.539 (React 19, TypeScript),
set up for AI coding agents. The agent rules are in [`AGENTS.md`](AGENTS.md), which `CLAUDE.md` imports. The
official Remotion Agent Skills are in `.agents/skills/`.

## Quick start

```bash
cd motion
```

```bash
npm install
```

```bash
npm run dev
```

The Studio opens at http://localhost:3000. The sample composition is at http://localhost:3000/Showcase.

Render the sample to an MP4:

```bash
npm run render
```

The output is `out/showcase.mp4`: 1920×1080, 30 fps, 11.6 s, with sound.

Create a new composition, registered and ready in the Studio:

```bash
npm run new -- PromoVideo --seconds 8
```

Render any composition:

```bash
npx remotion render PromoVideo out/PromoVideo.mp4
```

Run lint and the typecheck:

```bash
npm run lint
```

## Change the format

- **Resolution and frame rate:** edit `VIDEO` in `src/config/video.ts`. `FORMATS` has presets for square, portrait, vertical and 4K.
- **Duration of the sample:** edit the scene lengths in seconds in `src/compositions/Showcase/timeline.ts`.
- **Duration of a template composition:** edit the `<NAME>_SECONDS` constant in its file.

## Using a coding agent

Start the Studio with `npm run dev`. In a second terminal, run your agent from this folder:

```bash
claude
```

Codex, OpenCode and other agents work too. Then prompt, for example: *"Make a 10-second product teaser
with kinetic typography and a music bed"*.
